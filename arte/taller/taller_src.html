TALLER DE PIEZAS

Reemplaza las piezas del personaje de WAP con tus dibujos (PDF, EPS, AI o SVG) y exporta personaje.txt para el juego.

Piezas

cabeza

Suelta aquí el PDF, EPS, AI o SVG

Gris claro: la pieza original. La cruz dorada es la articulación (donde gira la pieza). Arrastra para mover, rueda para escalar, Shift+arrastrar para girar, flechas para ajustar fino.

Colores del dibujo: toca uno para que tome el color del traje del jugador.

El personaje

Peso del personaje: 0 puntos de tus piezas (máximo 6000, recomendado menos de 2500 para jugar en línea)

personaje.txt

  1. Copia el texto con el botón.
  2. En Android Studio, en app/src/main/assets/, crea o abre personaje.txt y pega todo.
  3. Aprieta ▶ con el teléfono conectado, o haz commit y push para que GitHub arme el APK.
